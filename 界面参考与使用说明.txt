星起半 HALFDAY BAKERY｜摄影提示词组合工具 v2

一、这次扩展了什么

这一版预设预设为 36 个场景、16 个机位角度、12 种光线和 12 种构图，配合产品、呈现状态与可编辑文字，组合成食品摄影提示词。实际可选内容和兼容组合数量以页面显示为准；组合数不等于最终图片一定互不重复。

场景说明食品在哪里、由什么承托、周围有什么；机位说明从哪里拍、看见顶部还是侧面；光线说明光从哪里来、亮暗与阴影怎样变化；构图说明产品在画面中的位置、占比与留白。

二、怎么看图示

每个选项使用可视化卡片，帮助比较机位、受光、阴影和摆位。卡片是构图与光线示意，不是 AI 实际生成结果，也不是对生成效果的保证。不同产品的真实外形、材质和模型表现仍会影响最终图片。

推荐顺序：选产品 → 选完整、切开等状态 → 选场景 → 看图选择机位、光线和构图 → 按需要修改文字 → 复制提示词到生图软件。

工具默认生成纯文字提示词，不要求上传白底食品图。配料用来描述食品组成，不代表把全部原料摆在桌面上。星起半以烘焙食品为主，默认不加入咖啡或其他饮品。

三、界面参考

1. Qwen Multi-Angle Camera Control
项目：https://github.com/amrrs/qwenmultiangle
协议：MIT，已核实项目协议说明。
借鉴点：把相机的水平位置、俯仰角和远近变成可视化控制，让机位变化更容易理解。原项目包含 Three.js 与模型 API 接入；本工具没有引入其 API 或运行环境。

2. Render Diagrams
项目：https://github.com/vaspoul/render.diagrams
演示：https://renderdiagrams.org/editor.html
协议：MIT，已核实 LICENSE 文件。
借鉴点：直接在画布上说明光线方向、位置关系和参数变化，让抽象术语变成可以看懂的示意。

本工具的界面、图示与代码独立实现，仅借鉴上述交互思路，没有复制上述项目的代码或图像资产。

四、本地使用

解压后打开 index.html 即可使用。提示词组合和界面图示在本地浏览器内完成，不需要外部网络、账号或模型接口。实际生成食品照片需要把提示词复制到你选择的生图软件，该软件是否联网由其自身要求决定。

如果上传到自己的服务器，按普通静态网页部署即可；具体上传文件以压缩包附带内容为准。
