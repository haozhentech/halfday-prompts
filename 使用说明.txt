星起半 · 食品摄影提示词组合工具
本地离线版 / 服务器部署版 · 2026-09-22

一、本地使用
1. 解压此压缩包。
2. 双击 index.html，用 Edge、Chrome 等现代浏览器打开。
3. 选择菜单产品或候选品，在三个页签中选场景、机位构图和光线。
   机位、光线、构图都有示意图；右侧同步显示当前选择。
   场景可按包装、日常、广告、手作筛选。
   点开“文字微调”可以改写任何一段，示意图会标注自定义。
4. 点击“复制完整提示词”，粘贴到你使用的生图软件。
本工具本身可以完全离线使用，无需安装、登录或填写 API Key。
如果浏览器限制剪贴板，页面会选中全文；按 Ctrl+C（Mac 为 Command+C）复制。

二、服务器部署
index.html 是一个完整文件，已内置全部界面、脚本和预设。
有宝塔或 1Panel 等网站面板：新建静态网站，把 index.html 上传到该网站根目录即可。
已有静态网站：可以新建 halfday 子目录，把 index.html 放进去，通过 /halfday/ 访问。
不需要 Node.js、Python、数据库、后端服务或构建命令。
压缩包中的 nginx-example.conf 是新建独立站点时的配置示例，需修改域名和目录；不要覆盖已有站点配置。
域名解析、HTTPS 和已有服务器的具体配置，需要按你的服务器情况设置。

三、内容
32 款菜单产品 + 32 款候选品；支持自定义产品。
36 个场景、16 个机位、12 种光线、12 种构图、5 种状态及 32 种可选新增风味。
默认纯文字生图；也可切换图片辅助。
每款 71,282 组兼容预设，64 款合计 4,562,048 组。
另有 3 种景深、5 种画幅，未计入上述数字。
这是参数组合数量，并不保证实际生成图片全部不同。

四、使用范围
本网页只组合提示词，不生成或上传图片；图片由你选择的生图软件生成。
当前输入仅在本次页面会话内生效，刷新或关闭后恢复默认，请及时复制需要保留的提示词。
本地版为当前版本快照，后续线上版本更新不会自动同步到这个文件。

五、新增：黄金组合
每个场景都有一套推荐参数，共36套。选择场景会自动套用；可以继续微调，或点击“套用这组”恢复推荐机位、状态、光线、构图、画幅与景深。
“换一组”默认从黄金组合中随机，旁边也能切换为自由探索。
黄金组合是按摄影与包装结构策划的推荐，不是特定生图模型中的成功率保证。

六、新增：同场景套图
1. 选好一个场景，套用黄金组合或自行微调。
2. 点击“锁定当前场景”，再点左侧其他产品：只更新食品资料和对应切面。
3. 展开“多款一起做”，勾选所需产品；也能直接选菜单32款或候选32款。
4. 点击生成。每款提示词可单独复制，也可以复制整组或下载TXT。
5. 点“解锁”可调整环境。更改设置或切换产品后，已有批量结果会失效，需要重新生成。
锁定内容：场景、包装、机位、构图、光线、景深、画幅、配色和共用要求。食品状态类型沿用；切法和内部结构按各款更新。
批量中只有当前款沿用你在本页编辑的配方和新增风味，其余使用各自菜单资料。
自定义产品编辑只在该款当前页面生效，离开它后会从批量选择中移除，避免输出空白产品。
锁定的是提示词设定；仅凭文字无法保证模型生成的背景逐张完全相同。需要完全同景时，在支持图片参考的软件中复用第一张场景图。

七、新增：切面与包装
64款各有独立切法、内部结构与防错约束，写明切分方向、同一份来源、保留部分和馅料位置。
包装重点场景固定容器种类、零件连接、开合方向、内外颜色、承托和食品数量。可闭合纸盒保留顶部净空，并限制容易被盒壁挡住的机位。
所有切面资料均是基于菜单组成的概念结构，尚非真实门店配方或试制结果。改动原料后，请同步编辑“切面内部”与“本款切面避免项”。
